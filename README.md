# Housefix Frontend
The web application for the Housefix Backend developed with TypeScript and the React framework, serving as the user interface for managing customers and readings of the companies in the house management sector using this application. 

---

- [Start Webapp locally](#start-webapp-locally)
- [Webapp Usage](#webapp-usage)
- [Gimmicks](#gimmicks)

---

## Start Webapp locally
Development mode (with hot reload): `npm run dev`\
Local build preview: `npm run preview`
> Note: All npm (Node Package Manager) packages must be installed!\
> Use `npm i` or `npm install` to do that

## Webapp Usage
The Webapp is accessible in Dev-Mode at http://localhost:3000 or in the Preview at http://localhost:4000
> Note: Currently the Backend must be available at http://localhost:8080 to be able to see and use the full functionality

## Gimmicks
- Slot Machine (showing on Home and All Readings page when backend is not available)
- Authentication and Authorization System to access the ressources
- Import/Export functionality for all data tables
